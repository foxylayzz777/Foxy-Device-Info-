## 📱 About

**Foxy Device Info** is an Android utility app created under the **FoxyPlayzZ** project/brand.

It is designed to provide users with useful device, hardware, system, connectivity, sensor and performance information through a clean and easy-to-use interface.

The goal is to make technical device information simple to understand without unnecessary complexity.

## 🛠️ Technical Overview

Foxy Device Info is an Android application built using Android system APIs and hardware capabilities.

The application declares support for features including:

- Internet and network state
- Wi-Fi
- Bluetooth
- Camera
- Audio/microphone
- Notifications
- Hardware sensors
- Vibration
- Android device/system information
- Android App Widgets

Hardware capabilities are optional where appropriate so the application can work across different Android devices.

## 🔐 Permissions & Privacy

Some features may require Android permissions.

Examples include:

- **Camera** — camera-related functionality
- **Microphone** — supported audio tests
- **Bluetooth** — Bluetooth information
- **Network/Wi-Fi** — connectivity information
- **Notifications** — notification features
- **Sensors** — hardware/sensor diagnostics

Permissions should only be requested when required by the corresponding feature.
